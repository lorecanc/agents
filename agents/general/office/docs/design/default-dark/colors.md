# Default Dark Design System

Fallback dark theme for presentations with dark backgrounds.

## Color Tokens

| Token | Hex | Role |
|---|---|---|
| `Charcoal` | `#0f172a` | Page background |
| `Slate 800` | `#1e293b` | Surface / card background |
| `White` | `#ffffff` | Primary text |
| `Slate 300` | `#cbd5e1` | Secondary text |
| `Cyan 400` | `#22d3ee` | Primary accent |
| `Amber 400` | `#fbbf24` | Secondary accent |
| `Slate 700` | `#334155` | Borders / dividers |
| `Emerald 400` | `#34d399` | Success / positive |
| `Red 400` | `#f87171` | Error / warning |

## Background-Foreground Rules

| Background | Foreground |
|---|---|
| Charcoal (`#0f172a`) | White, Cyan 400, Amber 400 |
| Slate 800 (`#1e293b`) | White, Cyan 400 |
| Cyan 400 (`#22d3ee`) | Charcoal |
| Amber 400 (`#fbbf24`) | Charcoal |
| White (`#ffffff`) | Charcoal, Cyan 400 |
