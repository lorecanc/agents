# Default Light Design System

Fallback theme used when no design system is specified.

## Color Tokens

| Token | Hex | Role |
|---|---|---|
| `White` | `#ffffff` | Page background |
| `Slate 50` | `#f8fafc` | Surface / card background |
| `Slate 900` | `#0f172a` | Primary text |
| `Slate 500` | `#64748b` | Secondary text |
| `Blue 600` | `#2563eb` | Primary accent |
| `Amber 500` | `#f59e0b` | Secondary accent |
| `Slate 200` | `#e2e8f0` | Borders / dividers |
| `Emerald 500` | `#10b981` | Success / positive |
| `Red 500` | `#ef4444` | Error / warning |

## Background-Foreground Rules

| Background | Foreground |
|---|---|
| White (`#ffffff`) | Slate 900, Blue 600, Amber 500 |
| Slate 50 (`#f8fafc`) | Slate 900, Blue 600 |
| Blue 600 (`#2563eb`) | White |
| Amber 500 (`#f59e0b`) | Slate 900 |
| Slate 900 (`#0f172a`) | White, Blue 600, Amber 500 |
