# Craft Anything

## Document observed behavior

Read the project's investigation brief and existing findings with `core_investigation_show` when
resuming. For a new question, identify the target, the behavior to observe and what would answer
the question. Link each finding to its evidence ID. Keep an unresolved question with the
observation that would settle it. Include cited findings and open questions in the handoff so
another person can verify them.

## Generate a game asset

Choose the output from its use in the scene. For a background, specify framing and aspect ratio.
For a prop, specify silhouette, viewing distance and mesh detail. Check the generation cost and
remaining project budget before submitting a job. Use the returned asset path in the target
scene and check scale, framing or silhouette there before spending on another variation.
