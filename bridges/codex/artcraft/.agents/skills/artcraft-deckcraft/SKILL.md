# DeckCraft

Start with the slide's message and the deck's existing layouts. Use editable text, shapes and
charts when the recipient will revise them. Use `inspect_slide` on the target slide for shape
IDs and bounds before changing a selection. Render the slide at presentation size to catch
clipped text, overlap and labels too small to read.

When bringing in a chart from a workbook, use the verified categories, series and units. Check
that its labels remain legible alongside the slide title.

If the recipient needs to edit chart data, reopen the exported presentation in the intended
editor when available. Change one data point on a copy and check that the plotted value updates.
Report which editor you verified.
