# LightCraft

Use `query_photos` to identify the target photo and `list_controls` to find the available
adjustments. Check the active photo and selection when applying settings across a set, since
editing one photo can change that selection. Preview a representative image before applying a
shared adjustment, then check outliers for clipping or an unsuitable crop. If the desktop app
already owns the library, use its supported bridge for live edits so only one session writes the
catalog.

For a set with mixed lighting, group by exposure conditions before synchronizing adjustments.
Confirm the export selection against the intended photo IDs.
