# PDFCraft

Open the source, retain its document ID and use `text_find` or `page_render` to locate the
target. Check the page numbering in the tool schema before a page operation. For a reorder,
verify the resulting sequence by content. For a text edit, extract the affected passage and
render the page to check placement. Save to the intended output path.

For a combine or split, identify pages by a short excerpt or visible heading as well as their
original index. Re-read the page order after a move before making another index-based edit.
