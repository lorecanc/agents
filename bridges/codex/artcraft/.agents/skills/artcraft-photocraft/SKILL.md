# PhotoCraft

Use `doc_inspect` to identify the canvas, layer stack and selection. Put local corrections on a
layer or mask when the edit needs to stay adjustable. Preview a retouched region at pixel scale
for edge artifacts and the full image at delivery size for composition. Keep the layered project
when requested and choose an export that preserves any required transparency.

For a composite, check the mask boundary against the intended background. Inspect the exported
asset at its actual placement size when it will appear in a layout.
