# gridcraft

CLI: `gridcraft-cli mcp` · 22 tool · dumped 2026-11-21

- `execute_command` — Run ANY GridCraft command by id with JSON params — every ribbon/menu action is a command. Find ids and parameter docs with list_commands. Examples: {"command":"cell.set","params":{"cell":"B2","input":"=SUM(A1:A9)"}}; {"command":"home.bold","params":{"range":"A1:C1"}}; {"command":"sheet.insert"}; {"command":"data.removeDuplicates","params":{"range":"A1:C20"}}. Most commands act on the current selection when `range` is omitted. Programmatic calls never open dialogs: missing required params give an error.
- `list_windows` — List the open windows: window id, workbook (`doc`) id, title ("Book1", or "Book1:2" for a workbook's second window), unsaved changes, active and hidden. Pass a `window` or `doc` id to other tools to act there.
- `list_commands` — List GridCraft commands: id, label, ribbon path, shortcut, a parameter description (`params`) and whether it can run right now. Use it to discover what execute_command can do (e.g. search "sort", "border", "chart", "sheet").
- `inspect_workbook` — Summary of the active workbook: title, path, dirty flag, sheets (name, used range, cell count, tables, charts, merges, filters, freeze panes), defined names, current selection and active cell, calculation mode and undo/redo history.
- `read_range` — Read cell values from a range as rows (2-D array). Numbers/booleans/strings are returned as JSON values, empty cells as null, errors as {"error":"#DIV/0!"}. Without `range`, reads the sheet's used range. formulas:true returns formula text ("=SUM(B2:B4)") for formula cells; formatted:true returns the displayed text ("$1,234.00", "12%").
- `write_range` — Write a 2-D array of values starting at the top-left cell of `range` (rows of cells). Numbers, booleans, null (clears) and strings are accepted; strings starting with = are formulas ("=SUM(B2:B4)"), other strings are parsed like typed input ("12%", "1/2/2024", "$5") unless `parse` is false, which stores them as the text they are. The result's `converted` lists the strings that were read as something else. One undo step. Example: {"range":"A1","values":[["Item","Cost"],["Rent",1200]]}.
- `set_cell` — Enter one cell exactly as if typed: a number, text, or a formula starting with = ("=AVERAGE(B2:B9)"). Dependent cells recalculate. Returns the command result; use get_cell to read the computed value.
- `get_cell` — Details of one cell: computed value and type, formula, display text, raw input, spill range, style, merge, comment and hyperlink.
- `evaluate_formula` — Evaluate a formula against the active sheet WITHOUT changing any cell, e.g. "=SUM(B2:B10)/COUNT(B2:B10)" or "=VLOOKUP(\"x\",A:B,2,FALSE)". `cell` sets the formula's position for relative references and ROW()/COLUMN(). Use English function names and `,` between arguments; a formula that couldn't be entered in a cell is an error saying why.
- `select` — Set the selection (what commands without a `range` param act on). Multiple areas with commas: "A1:B2,D4". A "Sheet2!A1" prefix switches sheets.
- `format_range` — Apply several formats to a range in one call: bold, italic, underline, font name/size, font color, fill color, number format, horizontal alignment, wrap, borders. Colors are "#RRGGBB" (fontColor also "auto", fillColor also "none"). numberFormat is a name (General, Number, Currency, Accounting, Comma, Percentage, Short Date, Long Date, Time, Fraction, Scientific, Text) or a format code ("#,##0.00", "0%", "yyyy-mm-dd"). Each property runs one command; the result lists them.
- `insert_chart` — Insert a chart from a data range (first row/column used as series names and categories, like Excel). Returns the chart id.
- `create_table` — Format a range as an Excel table (structured references, banded rows, filter buttons). The first row is the header by default.
- `sort_range` — Sort a range by one or more columns. keys: [{"column":"B","order":"desc"}, …] or just ["B"]. Without `range` the current region around the selection is sorted; header detection follows Excel unless `header` is given.
- `filter` — Filter rows by a column (turns on AutoFilter on the current region, or `range`, when needed). Give `values` (keep rows whose cell text is one of them), `custom` ({op:">", value:"10", op2?, value2?, and?}), `top` ({count, bottom?, percent?}), or clear:true to remove this column's filter.
- `open_workbook` — Open a workbook file (.xlsx, .xlsm, .xls, .xlsb, .ods, .csv, .tsv, .txt, .json) and make it active. Excel 97-2003 .xls imports values, formulas and number formats; XLSB and ODS import worksheet data and cached formula values only; check the returned warnings.
- `save_workbook` — Save the active workbook. The format follows the extension (.xlsx default; .csv/.tsv save the active sheet; .json; .html). Without `path` saves to the workbook's current file.
- `new_workbook` — Create a new workbook and make it active: blank, or a built-in sample ("budget", "sales", "grades").
- `undo` — Undo the last change(s) to the active workbook.
- `redo` — Redo the last undone change(s).
- `screenshot` — Save a PNG screenshot of the GridCraft window to `path`. Desktop app only (`gridcraft-cli mcp --connect 7979`).
- `list_functions` — List worksheet functions: name, category, signature and description. Filter with `search` (name or description) or `category`.
