# FigCraft

Inspect the parent frame with `get_node` before placing a child. Use parent-relative coordinates
for free placement and the parent's padding, gap and sizing rules for auto layout. Edit a
component when the change should propagate, or the instance for a local override. Inspect the
resulting bounds and preview the frame with representative text. For review work, use the
comment's anchor to find the node.

For a prototype change, follow the interaction from its source frame and check the destination
and state. A screenshot of the starting frame verifies appearance only.
