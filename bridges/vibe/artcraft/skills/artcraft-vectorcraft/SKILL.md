# VectorCraft

Use `doc_inspect` to identify the artboard, then check the coordinate system for the drawing
command. Build repeated elements from shapes or paths with consistent strokes and fills. Drawing
can change the selection, so retain object IDs for subsequent styling. Check the silhouette and
stroke weight at the artwork's intended size.

For a logo or icon, inspect the smallest requested size before export. Check that counters stay
open, strokes remain visible and the artboard crops the intended artwork.
