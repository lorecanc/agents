# WordCraft

For a revision, use `list_documents` to identify the open document. Find the passage and inspect
its paragraph or table context. Reuse its named styles so edits reflow with the surrounding
text. Select by text when possible. For a positional edit, get the story, block and byte offset
from the document. Render the affected pages, including the following page if a heading or table
moved across a break.

For a new report, establish the heading hierarchy before filling sections. Use a real table for
tabular data so its rows and cells survive document export.
