# cadcraft

CLI: `cadcraft-cli mcp` · 12 tool · dumped 2026-11-21

- `command_line` — Type one line at the CADCraft command line, exactly as a user would at an AutoCAD-style prompt. Starts commands by name or alias (LINE, L, CIRCLE, C, PLINE, RECTANG, MOVE, TRIM, OFFSET, ZOOM…) and answers the active prompt: points `x,y`, relative `@dx,dy`, polar `@dist<angle`, distances, keywords (e.g. `c` for Close), empty text = Enter. Spaces act as Enter, so `circle 0,0 5` works in one call. Returns the new prompt and command-line output, and `error` when the line was refused.
- `script` — Run a multi-line script (like an AutoCAD .scr file): one or more inputs per line, blank line = Enter.
- `execute` — Run any command with JSON parameters (no prompts or dialogs). Use list_commands to find ids and parameter docs. Examples: line {points:[[0,0],[10,0]]}, circle {center:[0,0], radius:5}, layer.new {name:"Walls", color:"red", current:true}, move {handles:["10A"], delta:[5,0]}, zoom {mode:"extents"}.
- `list_commands` — List commands with ids, labels, menu paths, aliases and parameter docs. Optional filter: a substring of the command id, label or an alias.
- `inspect_drawing` — Summary of the active drawing: entity counts, extents, layers, styles, blocks, layouts, selection, undo history and (optionally) entities with handles and geometry.
- `query_entities` — Entities filtered by type (Line, Circle, Polyline…), layer, current selection (selected:true; active space only) and/or a window [[x0,y0],[x1,y1]] (objects whose geometry is inside or crosses it; crossing:false = entirely inside). Returns count (all matches), returned (this page) and entities; page with offset and limit (default 500).
- `render` — Render the active drawing to a PNG and return it as an image content block (content[0].type is "image", not text): fitted to the extents by default, or just the area `window` [[x0,y0],[x1,y1]] (drawing units), e.g. one sheet or one room of a large drawing. With a window and no size the image is 1600 px wide with the window's shape. `background`: "dark" (the canvas; the default without a plot style), "white" (the default with one, as a plot prints on paper), "paper" or "#rrggbb"; colour 7 is drawn white on a dark background and black on a light one, as on a plot. `plot_style`: a plot style table, e.g. "monochrome.ctb" (every colour black, as most plots) or "grayscale.ctb", which make light colours readable on white; "none" (or "") draws every object with its own properties, also in a layout that shows its own plot styles (without `plot_style` such a layout draws with its table, as on screen). An unknown background or plot style is refused.
- `find_text` — Read the drawing's texts: TEXT, MTEXT (formatting removed), block attributes and multileaders, each with its text, insertion point `at`, height, rotation, style, layer and handle. Filter by `contains` (any case), `layer` and/or `window` [[x0,y0],[x1,y1]] around the insertion points; page with offset and limit (default 200). Use it to find room names, sheet titles and notes without reading all the geometry.
- `new_drawing` — Create a new drawing (imperial by default, or metric).
- `open` — Open a DXF or DWG file.
- `save` — Save the drawing (DXF or DWG by extension). A .svg, .png or .pdf path exports instead: the drawing keeps its name and unsaved changes.
- `cancel` — Press Escape: cancel the running command (or clear the selection).
