# CadCraft

Establish drawing units, origin and layers from the drawing. Use the command line for familiar
drafting operations or discover a structured command when explicit parameters make the geometry
easier to check. Use `query_entities` to check endpoints, radii and closed profiles numerically.
Render the drawing at the intended scale to check linework and dimensions.

For a profile destined for extrusion, check for gaps and duplicate segments before handing it to
the modeling step. Include the drawing units in the handoff.
