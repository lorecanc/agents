# DesignCraft

Set page geometry, then place frames in spread coordinates and flow each story through its
frames. After changing copy or type size, inspect for overset text and render the spread to
check columns, image crops and alignment across facing pages.

Use `get_story` to read the complete copy and compare its ending with the rendered page. A last
line can disappear beyond a frame even when the rendered page looks balanced.
