# EffectCraft

Build the composition in layer order. Use `get_layer` to find the target property's path, then
set its value or place keyframes in composition time. For a title fade, for example, render the
start, an intermediate frame and the end. The middle frame reveals interpolation that the
endpoints alone cannot show.

When the composition goes into an edit, match the destination frame size, rate and duration.
Preview transparent elements against the intended footage or a contrasting background.
