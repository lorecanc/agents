# GridCraft

Inspect the sheet names, used ranges and existing formulas before choosing the write range. Keep
inputs and calculations distinguishable. Write rectangular data together and use formulas for
derived values. Use `read_range` in formula and value modes on representative cells, especially
the first and last row of a filled formula. Check totals against the inputs before formatting.

When importing identifiers such as 00123, check the resulting cell type before filling the
column. When passing numbers to another app, include headers, units and the range used.
